# Security reporting

SiftQuery is currently an unreleased 0.x library. Only the latest development revision is maintained; production security support has not been established.

Do not put exploit details, credentials, real tenant data or private SQL in public issues. Report a suspected vulnerability privately to the project maintainer through the private contact channel used to obtain this source. If a public repository enables private security advisories, use that channel.

A public repository URL and a dedicated reporting contact must be configured by the maintainer before public release. No email address or repository ownership is inferred from the local checkout.

Reports should describe the affected revision/features, a minimal reproduction using disposable data, expected and actual behavior, and potential impact. SQL injection, authorization-scope bypass, cursor forgery, unbounded resource use and connection-context leakage are relevant security issues.
